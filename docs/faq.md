# 常见问题与已知限制

### 文字和 AutoCAD 里看起来不完全一样？

浏览器无法使用 SHX 字体，文字用系统字体绘制，字宽和笔画与 AutoCAD 略有差异，位置和高度一致。可以通过 [`fontFamily`](/api/options) 指定字体。

### 为什么有些对象没显示？

打开图纸后，右下角会列出未显示的对象类型和数量，常见的有：

- **IMAGE**：只显示边框，外部图片文件不在 DWG 中
- **外部参照（XREF）**：引用的其他 DWG 文件无法在浏览器中获取
- **三维实体 / 面域**：只显示能从 ACIS 数据中解析出的线框
- **代理对象**（天正、浩辰等专业软件的自定义对象）：需要在原软件中“分解”或“导出为 T3”后再预览
- **WIPEOUT、OLE 对象、PDF / DWF 参考底图**：不支持

### 天正建筑的图纸能看吗？

天正对象是代理对象，直接打开时墙、门窗等会缺失。请在天正中使用“图形导出”（导出为 T3 格式）后再预览。

### 图纸很大时会卡吗？

解析在 Web Worker 中进行，界面不会卡死。约 10 万个实体（900 万顶点）的图纸，在普通笔记本上解析加生成图形约 2 – 3 秒，之后缩放平移流畅。超过 `maxVertices`（默认 1200 万）时几何会被截断并提示，文字仍然完整显示。

### 支持编辑吗？

不支持。本组件只读。需要编辑请使用专业 CAD 软件。

### 文件会上传到服务器吗？

不会。所有解析和渲染都在浏览器本地完成。`src` 为 URL 时组件只是从该地址下载文件。

### 加密或损坏的图纸？

损坏的图纸会尝试以容错模式读取，尽量显示能解析的部分。带密码的 DWG 不支持。
